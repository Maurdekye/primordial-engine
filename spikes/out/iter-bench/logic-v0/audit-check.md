## Why each accepted flag is accepted (the allow file's lines)

* class line 34, `inline-asm`: Rust inline assembly (asm!, global_asm!, naked_asm!) is Rust: allowed by D1 (design 20.2, settled 2026-10-30 19:11Z as recommended); in our own crates pe-core/src/fpenv.rs and box3d-fork/src/worker_pool.rs read and write MXCSR / FPCR
* class line 35, `inert-sources`: ships C/C++/asm files but has no build script, so cargo never compiles them (design 20.2: "crates that ship but do not compile C/asm files ... harmless"); today cc (its test sources) and ttf-parser (its C API)
* class line 36, `windows-import-lib`: prebuilt import stubs for Windows system DLLs, an OS boundary D1 accepts (design 20.1: "ships prebuilt .lib stubs, not C source")
* allow line 39, `blake3 1.* compiles-native with=pure`: with `pure` its build.rs takes the Rust-intrinsics paths and compiles no C or asm (blake3 1.8.7 build.rs:343-371; design 16.6, 20.3); on x86_64 it still runs the C compiler once to probe AVX-512 flag support (c_compiler_support, build.rs:161-195) and discards the answer, so nothing it compiles is linked
* allow line 40, `wayland-sys 0.31.* links-native with=dlopen`: Linux only, through wgpu-hal in the video tool: with `dlopen` its build.rs returns before calling pkg-config ("Do not link to anything", 0.31.11 build.rs:4-7) and libwayland is loaded at run time, a system library (design 20.1)
* allow line 41, `ash 0.38.* links-native without=linked`: Vulkan bindings, through wgpu-hal in the video tool: its build.rs emits rustc-link-lib=vulkan only with `linked` (0.38.0 build.rs:2-21); without it (`loaded`) the Vulkan loader is loaded at run time (design 20.1)
* allow line 42, `rayon-core 1.* links-native`: `links = "rayon-core"` only stops two rayon-core versions in one build; its build.rs links nothing ("we're not *actually* linking to anything", 1.13.0 build.rs:1-7)
* allow line 43, `wasmtime 50.* compiles-native in=spikes/iter-bench/host`: the iteration benchmark's host (iteration-benchmark 5, D12 evidence) runs guests in wasmtime to compare runtimes; on Linux and macOS wasmtime's build.rs compiles helpers.c whatever the features (design 20.2); a benchmark, never the engine
